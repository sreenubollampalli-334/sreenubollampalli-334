
## 🎓 StudySphere — AI-Powered Learning Platform

**Learn Smarter. Together.**

StudySphere is a full-stack, AI-powered study workspace that brings academic planning, personalized tutoring, document-based learning, practice, revision, and peer collaboration into one unified platform.

Designed for college students and independent learners, StudySphere combines secure backend engineering, intelligent learning workflows, and real-time collaboration.

**Development Status:** Core development Phases 00–14 completed. Optional extensions are planned for Phase 15.

### Key Features

- 🔐 Secure Authentication, Email Verification & Role-Based Access Control
- 📅 Study Planner, Recurring Tasks & Exam Deadline Tracking
- ⏱️ Focus Sessions, Daily Goals & Study History
- 📂 Private Study Materials, Resource Sharing & Access Control
- 🤖 Streaming AI Study Mentor (Google Gemini / OpenAI via Spring AI)
- 📄 AI Document Learning with PDF/TXT Processing, RAG & Source Citations
- 📝 AI Quiz Generation with Server-Side Grading & Answer Explanations
- 🧠 AI Flashcard Generation with Spaced-Repetition Scheduling
- ✅ Human-in-the-Loop AI Study Plan Approval
- 📈 Learning Analytics, Topic Mastery & Personalized Recommendations
- 🤝 Intelligent Study Partner Matching
- 💬 Real-Time Private Messaging & Collaborative Study Rooms
- 👥 Course Communities, Shared Notes & AI-Assisted Collaboration
- 🏆 XP, Streaks, Achievements & Notifications
- 🛡️ Administrative Moderation, Auditing & Monitoring
- 📱 Responsive Across Desktop, Tablet & Mobile

### Tech Stack

**Java 21 • Spring Boot • Spring Security • Spring AI • Google Gemini • OpenAI • React.js • TypeScript • Tailwind CSS • MySQL • Qdrant • WebSockets • SSE • Flyway • Maven • GitHub Actions**

### Engineering Focus

- Secure REST API architecture and modular backend design
- Authentication, authorization & resource-level access control
- AI integration with streaming responses and provider configuration
- Retrieval-Augmented Generation (RAG) with authorized document access
- Human-in-the-loop AI workflows with transactional and idempotent updates
- Server-side quiz grading and spaced-repetition algorithms
- Real-time communication using WebSockets/STOMP
- Personalized learning analytics and recommendation algorithms
- Relational database design, Flyway migrations & vector search
- Automated unit, integration & frontend testing
- Production readiness, monitoring, auditing & deployment workflows
